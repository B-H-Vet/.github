# API de Gestión Integral para Clínica Veterinaria

Esta API permite administrar de forma centralizada la operación de una clínica veterinaria.

## Módulos principales

- Gestión de inventarios
- Gestión de usuarios
- Gestión de roles
- Gestión de veterinarios
- Gestión de mascotas
- Gestión de facturas
- Gestión de citas
- Gestión de servicios

## Objetivo

Facilitar el control de los procesos administrativos y clínicos en un solo sistema, mejorando la organización y el seguimiento de la atención veterinaria.
